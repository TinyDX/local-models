# Local Models · 构建工作区说明

这个文件夹里是 **Local Models 本地推理程序**的全部构建资料。
交付给别人的东西是上一层的 `Bonsai2-Engine-Pack.zip`；这里是可以改代码、重新打包的源头。

---

## 怎么改代码并重新打包

### 1. 编译

用系统自带的 C# 编译器（不需要装 Visual Studio / .NET SDK）：

```powershell
$b   = '.'
$src = "$b\源码"
$out = "$b\编译产物"
$csc = 'C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe'

# 启动器（网页页面要一起嵌进去）
& $csc /nologo /target:winexe /platform:anycpu /optimize+ `
  "/out:$out\Local Models.exe" `
  "/win32icon:$src\bonsai.ico" "/resource:$src\bonsai.ico,app.ico" `
  "/resource:$b\网页源码\index.html,index.html" `
  /reference:System.dll /reference:System.Drawing.dll /reference:System.Windows.Forms.dll `
  "$src\BonsaiTray.cs" "$src\Theme.cs" "$src\Win11Menu.cs" "$src\Win11Tabs.cs" `
  "$src\WebHost.cs" "$src\LaunchConfig.cs" "$src\Hardware.cs"

# 安装器
& $csc /nologo /target:winexe /platform:anycpu /optimize+ `
  "/out:$out\Bonsai2-Setup.exe" `
  "/win32icon:$src\bonsai.ico" "/resource:$src\bonsai.ico,app.ico" `
  /reference:System.dll /reference:System.Drawing.dll /reference:System.Windows.Forms.dll `
  "$src\Installer.cs" "$src\InstallCore.cs"

# 卸载器
& $csc /nologo /target:winexe /platform:anycpu /optimize+ `
  "/out:$out\Uninstall.exe" `
  "/win32icon:$src\bonsai.ico" "/resource:$src\bonsai.ico,app.ico" `
  /reference:System.dll /reference:System.Drawing.dll /reference:System.Windows.Forms.dll `
  "$src\Uninstall.cs" "$src\Theme.cs"
```

### 2. 更新打包源

把编译产物覆盖进 `打包源\payload\`：

```powershell
$b = '.'
Copy-Item "$b\编译产物\Local Models.exe" "$b\打包源\payload\Local Models.exe" -Force
Copy-Item "$b\编译产物\Uninstall.exe"    "$b\打包源\payload\Uninstall.exe" -Force
Copy-Item "$b\网页源码\index.html"        "$b\打包源\payload\webui\index.html" -Force
```

### 3. 打包

用 `编译产物\调试工具\Repack.exe`（三个参数：安装器、payload 目录、输出 zip）：

```powershell
$b = '.'
& "$b\编译产物\调试工具\Repack.exe" `
  "$b\编译产物\Bonsai2-Setup.exe" `
  "$b\打包源\payload" `
  '..\Bonsai2-Engine-Pack.zip'
```

约 25 秒出 4.54 GB 的成品。压缩策略：三个引擎 exe 不压缩（已压过，再压没收益），其余用 Fastest。

## 程序的关键设计（改的时候别踩坑）

### 路径

- **所有路径都以 exe 所在目录为基准**，不写死任何机器路径
  - `engine\` 引擎、`models\` 模型、`webui\` 网页、`launch-config.json` 配置
- 日志写到 `%LOCALAPPDATA%\LocalModels\engine.log`

### 模型 ID

- **模型 ID = `models\` 里那个 `.ninfer` 的文件名（去掉扩展名），一字不改**
  - `bonsai2_27b_ternary_ptq1_native_mtp.ninfer` → `bonsai2_27b_ternary_ptq1_native_mtp`
- 同一个值给三处用：引擎的 `--model-id`、网页请求的 `model` 字段、界面显示
- 换模型只换文件即可，ID 自动跟着变

### 引擎参数

- 在 `BonsaiTray.cs` 的 `EngineArgTemplate` 里，`{model}` 是模型 ID 占位符
- 界面显示的「逻辑上下文 / 推测解码」从这份模板里读，保证界面与实际启动参数不会不一致

### 已知的两个坑（都已在代码里注明）

1. **日志文件读取必须用 `FileShare.ReadWrite`**
   启动器自己持着日志文件（写入端），`File.ReadAllLines` 默认的 `FileShare.Read`
   不允许写入端存在，会抛 IOException 导致读不到日志。

2. **跨线程刷新控件要用窗口对象做编组**
   `控件.InvokeRequired` 在标签页不可见时可能返回 `false`（句柄未创建），
   会把 UI 操作丢到后台线程执行。

### 安装器的行为

- 释放 `payload\` 的**整棵目录树**到安装目录；只对 `engine\` 下的引擎 exe 做架构过滤
  （本机是 sm_120a 就只留 `ninfer-serve-120a.exe`，另外两档不落盘，省 3 GB）
- 写 `launch-config.json`、建桌面与开始菜单快捷方式
- 在「设置 → 应用」注册卸载项
- 用 `netsh http add urlacl` 预留网页端口（否则手机/局域网访问会 400）—— 这一步会弹一次 UAC

### 卸载器的行为

- 先把自己复制到 `%TEMP%` 再运行，否则删不掉自己所在的安装目录
- **`models\` 默认保留**（是使用者自己的模型文件），要显式勾选才会一起删

### ★ 编译时必须带上 Version.cs

三个 exe 都要一起编译 `源码\Version.cs`，漏了会报「找不到 AppInfo」：

```powershell
# 启动器
"$src\Version.cs" "$src\BonsaiTray.cs" "$src\Theme.cs" "$src\Win11Menu.cs" "$src\Win11Tabs.cs" `
"$src\WebHost.cs" "$src\LaunchConfig.cs" "$src\Hardware.cs" "$src\AccessConfig.cs" `
"$src\ApiKeys.cs" "$src\Reasoning.cs" "$src\W11Ui.cs"

# 安装器
"$src\Version.cs" "$src\Installer.cs" "$src\InstallCore.cs"

# 卸载器
"$src\Version.cs" "$src\Uninstall.cs" "$src\Theme.cs"
```

**改完代码后的同步清单**（缺一不可，否则安装出来的还是旧版）：

1. `编译产物\Local Models.exe` ← 编译输出
2. `<你的安装目录>\Local Models.exe` ← 本机实际使用的那份
3. `打包源\payload\Local Models.exe` ← **安装程序释放的就是这一份**
4. `打包源\payload\Uninstall.exe` ← 卸载器同理
5. 重新跑 `Repack.exe` 出新的 zip（安装器不在 payload 里，是 Repack 的第 1 个参数）

**署名与许可**：引擎是 NInfer（Apache-2.0），上游 <https://github.com/1314521gjy/ninfer-fusion-kvmem>。
完整许可证文本随包装在 `licenses\` 目录，发布时请保留。

## 增量包（给已安装的用户）

已安装过的人**不需要重下 4.54 GB**，用这个 388 KB 的小文件即可跨版本更新：

`
LocalModels-Update-0.3.5beta.exe    396,800 字节 (387.5 KB)
SHA256: 5BD892288B1DCC3C737B29CB0F4DE942CD26373B952D1872007BD50698519ECF
`

它内嵌了当前版本的程序文件（Local Models.exe / Uninstall.exe / webui\index.html / 更新日志.txt），
双击运行会：

1. 自动找安装目录（读注册表 InstallLocation，找不到就让自己旁边找，再不行弹框让用户选）
2. 显示「已安装版本 → 新版本」并比对版本号（已是最新会禁用按钮）
3. 关掉正在运行的程序 → 替换程序文件 → 完成

**只替换程序文件**，models\、engine\、licenses\、各种 .json 配置、对话历史一律不动。

编译增量包（注意内嵌的是**已经编译好的** exe）：

`powershell
& $csc /nologo /target:winexe /platform:anycpu /optimize+ 
  "/out:$out\LocalModels-Update.exe" 
  "/win32icon:$src\bonsai.ico" "/resource:$src\bonsai.ico,app.ico" 
  "/resource:$out\Local Models.exe,Local Models.exe" 
  "/resource:$out\Uninstall.exe,Uninstall.exe" 
  "/resource:$b\网页源码\index.html,index.html" 
  "/resource:$b\打包源\payload\更新日志.txt,更新日志.txt" 
  /reference:System.dll /reference:System.Drawing.dll /reference:System.Windows.Forms.dll 
  "$src\Version.cs" "$src\Updater.cs" "$src\UpdaterForm.cs" "$src\UpdateMain.cs"
`

**顺序很重要**：增量包要在启动器、卸载器、更新日志都更新完之后再编译，否则内嵌的是旧文件。
